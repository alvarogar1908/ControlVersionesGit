# 4. Repositorio: GitHub

## ¿Qué es GitHub?

GitHub es un portal para alojar proyectos de desarrollo. Utiliza Git como sistema de control de versiones y permite consultar archivos y versiones de un proyecto. También facilita que desarrolladores y usuarios colaboren en su mejora.

## ¿Qué es un repositorio?

Un repositorio es como una carpeta en la que se guardan los archivos de un proyecto, por ejemplo, código, documentación o ejemplos. Puede ser:

- **Público:** visible para todo el mundo.
- **Privado:** con acceso restringido a usuarios autorizados.

## El archivo README

El archivo `README.md` contiene la información básica para conocer y utilizar el repositorio. Puede incluir:

- Nombre del proyecto.
- Descripción y créditos.
- Índice de contenidos.
- Instrucciones de uso.
- Licencia, cuando corresponda.

En esta práctica, el `README.md` incluye el índice que enlaza a cada apartado de la documentación.

## Colaboración en GitHub

GitHub permite que una persona cree un repositorio y que los compañeros hagan un fork para trabajar sobre una copia en su propia cuenta. Después pueden enviar una propuesta de cambios mediante un pull request. El responsable del proyecto revisa los cambios y, si los acepta, los integra mediante un merge.
