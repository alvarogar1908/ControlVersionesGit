# 1. Introducción

En los proyectos informáticos es importante producir documentación técnica que explique el proyecto, su organización y su uso. Para mantener esa documentación organizada y poder trabajar con otras personas se utilizan herramientas como Git, Markdown y GitHub.

- **Git** es un software de control de versiones distribuido que permite registrar los cambios de un proyecto y colaborar con otras personas.
- **Markdown** es un lenguaje de marcas que facilita dar formato a un texto mediante caracteres sencillos.
- **GitHub** es una plataforma web para alojar proyectos que utiliza Git como herramienta de control de versiones. Puede almacenar tanto documentación como software.

Estas herramientas permiten mantener un historial de cambios, documentar el proyecto y coordinar las aportaciones de los integrantes del equipo.

## Objetivo

El objetivo de esta práctica es aprender a organizar documentación en archivos Markdown y utilizar GitHub para colaborar mediante forks, commits, pull requests y la integración de los cambios.
